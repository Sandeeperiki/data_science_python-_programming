# Analyzing Student Performance Risk Through Academic and Lifestyle Factors
## Project Overview

This project focuses on data cleansing, preprocessing, exploratory data analysis (EDA), and insight generation using Python on a comprehensive student academic risk dataset. The dataset provides a holistic view of student performance by combining academic, behavioral, psychological, wellness, career development, and environmental factors.

The objective is to prepare high-quality data for analysis and identify patterns that influence student academic success and performance risk levels.

## Dataset Description

The dataset contains **1,200 student records** with **36 features** designed to capture multiple dimensions of student life. It combines academic performance metrics with behavioral habits, wellness indicators, career aspirations, and external environmental factors.

### Key Feature Categories

#### Academic Profile & Performance
- CGPA categories
- Academic programs and streams
- Attendance percentage
- Assignment completion frequency

#### Behavioral & Study Habits
- Daily study hours
- Productivity ratings
- Focus duration
- Revision frequency
- Study consistency

#### Psychological & Wellness Factors
- Stress levels
- Sleep hygiene
- Energy patterns
- Screen time distractions
- Procrastination and internal barriers

#### Career & Professional Development
- Career goal clarity
- Career interests (AI/ML, Cybersecurity, Digital Marketing, etc.)
- Participation in internships, projects, certifications, and hackathons

#### External Environment
- Family expectations
- Financial constraints
- Health-related challenges

## Target Variable

The dataset is designed to predict **Performance Risk Level**, categorized as:

| Risk Level | Description |
|------------|-------------|
| Low Risk | Strong study habits, positive wellness indicators, and clear career goals |
| Moderate Risk | Adequate performance with signs of stress, inconsistency, or uncertainty |
| High Risk | Significant academic challenges influenced by psychological or external factors |

## Project Objectives

- Assess data quality and identify inconsistencies.
- Handle missing values and duplicate records.
- Perform data cleansing and preprocessing.
- Conduct exploratory data analysis (EDA).
- Analyze relationships between academic performance and behavioral factors.
- Create visualizations to uncover trends and patterns.
- Generate insights that support future predictive modeling efforts.
